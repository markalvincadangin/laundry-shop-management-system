# Data Model: Audit Log System

## Entities

### `audit_logs` (PostgreSQL Table)
The core immutable record of all system events.

**Fields**:
- `id` (UUID, Primary Key): Unique identifier.
- `created_at` (TIMESTAMP WITH TIME ZONE): Server-side timestamp of the event. Default `NOW()`.
- `user_id` (VARCHAR(255)): Identifier of the actor (UUID string, or 'SYSTEM').
- `ip_address` (VARCHAR(45)): Originating IP address of the request.
- `user_agent` (TEXT): Originating User-Agent of the request.
- `action_type` (VARCHAR(50)): `INSERT`, `UPDATE`, `DELETE`, `READ`, `EXPORT`.
- `table_name` (VARCHAR(100)): Originating module/entity (e.g., `orders`, `users`).
- `record_id` (VARCHAR(255)): ID of the affected entity.
- `old_data` (JSONB): State of the entity before mutation (redacted).
- `new_data` (JSONB): State of the entity after mutation (redacted).

**Indexes**:
- `idx_audit_logs_created_at`: `(created_at DESC)`
- `idx_audit_logs_module_action`: `(table_name, action_type, created_at DESC)`
- `idx_audit_logs_user`: `(user_id, created_at DESC)`

**Triggers**:
- `trg_prevent_audit_tampering`: `BEFORE UPDATE OR DELETE` -> Raises Exception.

---

### AuditLogResponse (Java DTO / TypeScript Zod Schema)
The read-model returned to the frontend.

**Fields**:
- `id`: string
- `createdAt`: string (ISO-8601)
- `actor`: string (Username or 'System')
- `action`: string
- `module`: string
- `entityId`: string
- `summary`: string (Human-readable description generated by the backend)
- `diff`: object (JSON diff between old and new data)

## Security Rules
- DML privileges (`UPDATE`, `DELETE`, `TRUNCATE`) on `audit_logs` are revoked from the main application user.
